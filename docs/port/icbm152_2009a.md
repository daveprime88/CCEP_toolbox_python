# Preferred template: symmetric ICBM152 2009a

The user-selected `mni_icbm152_nlin_sym_09a_nifti.zip` replaces ext55 as the preferred
CCEP template. The supplied archive is installed locally at
`artifacts/templates/icbm152-sym-2009a/template.json`; full images remain ignored by
Git. Original files and COPYING are retained byte for byte. Historical ext55 bundles
and experiment records remain available for reproducing earlier work.

Archive SHA256:
`97068359213b5ec1b717f37a65ff260d1b8314954d8c6f573d3d047f574a838a`.
This identifies the supplied ZIP, not an independently authenticated upstream hash.

## Lightweight content check

The frozen baseline is
[icbm152_sym_2009a_content.json](../../reference/imaging/icbm152_sym_2009a_content.json).
Counts use **decoded NIfTI intensities after header scaling**, not raw stored int16
values. Two counts are recorded: exact `value != 0` and `abs(value) > 1e-6`.

| Original image | Exact nonzero voxels | Content voxels above 1e-6 |
|---|---:|---:|
| T1 | 8,675,289 | 8,675,289 |
| T2 | 8,675,289 | 8,675,289 |
| PD | 8,675,289 | 8,675,289 |
| T2 relaxometry | 2,543,335 | 2,543,335 |
| GM | 2,134,091 | 2,134,091 |
| WM | 1,950,834 | 1,950,834 |
| CSF | 1,760,845 | 1,760,845 |
| Brain mask | 1,886,539 | 1,886,539 |
| Eye mask | 1,229,127 | 1,229,127 |
| Face mask | 86,848 | 26,861 |

The face mask's nominal background decodes to about `-1.07e-14`, explaining the
exact/nonzero-count difference. Original masks' foreground decodes slightly above
one (about `1.000000059`). The importer validates masks against 0/1 with tolerance
1e-6, then saves a separate uint8 `registration_mask.nii.gz` using the original
brain mask >0.5. Registration uses that exact-binary mask; the original stays intact.

T1/T2/PD, relaxometry, brain mask and tissue priors have shape **197 × 233 × 189**,
1 mm spacing and RAS translation **(-98, -134, -72) mm**. Eye and face masks have
independent cropped grids: **197 × 103 × 74** at 1 mm and **46 × 32 × 59** at 4 mm.
The baseline records each image's full affine rather than forcing auxiliary masks
onto the T1 grid.

The probability checks require nonempty finite maps, common T1 geometry,
individual values in [0,1] (upper scaling tolerance 1e-6), GM+WM+CSF <=1.0001 and
nonzero combined support at every brain-mask voxel. On this archive:

- Maximum tissue sum: **1.0000305178**, within quantization tolerance.
- Uncovered brain-mask voxels: **0**.
- Minimum tissue sum inside the brain mask: **0.0360723**.

The maps are preserved without renormalization. The sum is not required to equal
one everywhere. Counts and range/coverage checks are a sanity regression, not
spatial/anatomical correctness, registration accuracy or SPM scientific acceptance.

## Run it

From the checkout with the imaging extra installed:

```sh
ccep --json image-template-install ~/Downloads/mni_icbm152_nlin_sym_09a_nifti.zip NEW_TEMPLATE_DIRECTORY
ccep --json image-template-check NEW_TEMPLATE_DIRECTORY/template.json --baseline reference/imaging/icbm152_sym_2009a_content.json
ccep --json image-template-register NEW_TEMPLATE_DIRECTORY/template.json native_t1.nii.gz NEW_REGISTRATION --moving-mask native_mask.nii.gz
```

The installed local check result is `artifacts/templates/icbm152-sym-2009a/content_check.json`.
A count mismatch returns exit code 3 and reports the image/field that changed.
Omitting `--baseline` still recomputes and verifies the bundle's stored summaries,
checksums, grids, mask values and tissue ranges/coverage. No registration is run.

The opt-in real-archive test and small synthetic tests run with:

```sh
CCEP_ICBM2009A_ZIP=~/Downloads/mni_icbm152_nlin_sym_09a_nifti.zip python -m pytest tests/test_template_2009a.py
```

All nine tests completed in about two seconds locally. Ordinary CI runs the eight
synthetic tests and skips the real-archive test unless its environment variable is
supplied; CI does not download or redistribute the full atlas.

## Tissue roles

The bundle exposes `tissue_priors = ["gm", "wm", "csf"]` and their image paths.
These are **three brain-tissue priors**. They do not include bone, soft tissue or
background priors required by the existing six-class `image-normalize` workflow,
and there is no CerebrA-style anatomical region-label atlas in this archive.
Do not create those classes or labels by subtraction or relabeling. Applying the
provided template priors to a native subject also requires the explicit inverse
registration mapping; matching array dimensions alone does not establish alignment.
